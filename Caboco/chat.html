Oi! O que é HTML?
O HTML (HyperText Markup Language, que significa Linguagem de Marcação de Hipertexto) é a linguagem padrão utilizada para criar e estruturar páginas na web. Pense nele como a "espinha dorsal" ou a estrutura básica de um site: é o HTML que diz ao navegador onde fica o título, os parágrafos, as imagens, os links e os botões de uma página.
